# Launching the panel

The panel is a local web app. You start it with the `agent-config` command, from a terminal or from inside your coding agent. Nothing is published on npm yet, so you install the command from a clone of this repository.

## Install the command

You need Node.js 23.6 or newer. Node runs the TypeScript sources directly, so there is no build step.

```sh
git clone <this repository> agent-config-manager
cd agent-config-manager
npm install
npm link              # or: npm install -g .
```

Both `npm link` and `npm install -g .` link the global `agent-config` command to your clone. Pulling new commits updates the command.

Use one of these two commands. A copied install, from a tarball or a registry, does not work: Node does not strip types from files inside `node_modules`, and `agent-config` then tells you to install from a clone.

## Start it

```sh
agent-config                       # same as: agent-config start
agent-config start --port 5000     # another port (default 4321)
agent-config start --no-open       # print the link, do not open the browser
agent-config --help
agent-config --version
```

The command prints a link like `http://127.0.0.1:4321/#token=…` and opens it in your browser. The panel works while the terminal stays open, and Ctrl-C stops it. `npm start` from the clone runs the same server.

## Open it from inside an agent

```sh
agent-config install-commands                   # every agent whose config folder exists
agent-config install-commands --agent gemini    # one agent: claude, codex, gemini, copilot or all
agent-config install-commands --dry-run         # list what would be written, change nothing
agent-config uninstall-commands                 # remove them again
```

Then start a new agent session and run the command. The agent runs `agent-config start` in the background and gives you the link.

| Agent | File written | Run it with |
| --- | --- | --- |
| Claude Code | `~/.claude/skills/agent-config/SKILL.md` (a skill) | `/agent-config` |
| Codex | `~/.codex/skills/agent-config/SKILL.md` (a skill) | `$agent-config`, or pick it from `/skills` |
| Gemini CLI | `~/.gemini/commands/agent-config.toml` (a custom command) | `/agent-config` |
| Copilot CLI | `~/.copilot/skills/agent-config/SKILL.md` (a skill) | `/agent-config` |

Codex has no `/agent-config` because it runs skills with `$`. The custom prompts it used to run with `/prompts:` are deprecated.

The installer writes one new file per agent and never edits an existing config file. Each file it writes contains the line `Generated by agent-config-manager`. The installer and `uninstall-commands` only replace or remove files with that line. If an `agent-config` file without the line already exists, the installer leaves it alone, reports `refused` and exits with status 1.
